# WhatsApp con Meta Cloud API

Implementación autorizada: destinatarios/consentimiento → prueba → cola → webhook/historial → web → recordatorios.

## Contratos y decisiones

- Reutilizar las cuatro tablas WhatsApp/configuración y PrismaService. Sin migraciones.
- SQL real inspeccionado en transacción READ ONLY: CHECK de estados, consentimiento,
  E.164, origen, intentos, parámetros; índices únicos y RLS habilitado sin políticas.
  No hay permisos específicos WhatsApp: JWT, propiedad y ADMINISTRADOR; vínculos
  ACTIVA y permiso de medicamentos para preferencias del adulto.
- Cada usuario registra su propio teléfono del perfil; altas siempre PENDIENTE.
  Consentimiento propio explícito WEB. Contactos: administrador registra evidencia
  externa FORMULARIO/OTRO; no se delega aceptación al familiar.
- Plantillas y versión Graph API configuradas exclusivamente en backend. Procesador
  y recordatorios deshabilitados por defecto. No enviar nada durante desarrollo.
- Cola SQL con FOR UPDATE SKIP LOCKED. Reintentar solo rechazo explícito 429 de Meta;
  timeout, 5xx y procesos interrumpidos quedan para revisión para evitar duplicados.
- HMAC sobre rawBody; estados idempotentes y sin regresión; historial mínimo.
- Recordatorios: adulto destinatario, PENDIENTE, medicamento activo, preferencias,
  máximo una notificación inicial más max_repeticiones, dentro de la ventana vigente.
  Exclusión por toma mediante bloqueo transaccional. Sin datos clínicos en plantilla.

## Ejecución y validación

1. Pruebas de consentimiento, propiedad, firma, estados y proveedor (fallar primero).
2. Módulo WhatsApp, DTO/OpenAPI, destinatarios, cola y webhook.
3. Integrar cola crítica existente y preferencias/recordatorios.
4. Exportar OpenAPI y generar tipos; feature web y estados reales.
5. Pruebas, lint, build en ambos repositorios y revisión independiente.

No se validará entrega real sin credenciales Meta, plantilla aprobada y destinatario
consentido. No se modifican datos reales en las pruebas automatizadas.

## Resultado de ejecución

Los cinco pasos quedaron implementados. Revisión independiente completada y
hallazgos importantes corregidos con regresiones: revocación concurrente,
acumulación de recordatorios, paginación de tomas, selector familiar y toma
confirmada mientras el worker espera. Suite backend: 85 pruebas; web: 14.
La validación externa de Meta queda pendiente por ausencia de credenciales y
plantillas, conforme a la instrucción expresa de preparar sin envíos reales.
